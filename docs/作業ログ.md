## 記載フォーマット

```
### YYYY-MM-DD 依頼の要約
- 依頼: 依頼者の依頼内容
- 実施: やったこと（変更ファイル・コミット・PR など）
- 結果/備考: 検証結果、未解決事項、次にやること
```
