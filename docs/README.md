## 資料の位置づけ（重要）

- **要件定義ワークブック**は、依頼者が思いついたことを書いたメモであり、確定した仕様書ではない。空欄・曖昧な箇所が多い。
- **引継ぎ資料**はClaudeが作成したもの。ワークブックの整理と、空欄箇所の「仮決め」を含む。仮決めは依頼者の承認を得たものではない。
- したがって、仕様に迷ったら**実装前に依頼者へ確認**し、確定したものを `決定事項.md` に記録する。
