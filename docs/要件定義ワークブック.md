# Step0 開発依頼
## ワーク0-1
〇明確に書かれていること。
- 出勤・退勤の登録（時刻も）機能
- ログイン認証機能
- 利用者名表示機能
- 当日のみのデータだけではなく複数日保存できる機能

〇確認が必要なこと
- 出勤および退勤以外の登録項目の有無　ex)休憩、休暇、有給休暇、遅刻/早退...
- 労働時間の設定とその時刻および数パターンのプリセット。
- 出勤および退勤の時刻から、設定した労働開始および終了時刻と突き合わせて強調表示するかの有無
- 上長の管理機能
- 勤怠情報の修正および削除、および追加申請

# Step1 顧客の要求

# Step4 業務のフロー
## ワーク4-1
| 利用者の行動 | システムが行うこと |
| ---- | ---- |
| ログイン | 認証サーバに接続し、入力されたidとpassを照合、あっていればログインで通す|
| 出退勤のボタン押下|DBに当該時刻付けで出勤（退勤）を保存する。|
| 記録の確認 | DBから該当ユーザのidで条件を絞り、過去日含むすべての結果を取得する。|
| 勤怠情報の修正 | tempとして保存し、実際のDBには反映しない。|
| (上長)申請の承認 | tempで保存された修正事項を本番DBに反映する。|
| 遅刻・早退のボタン押下 | DBに当該時刻付けで記録する|

# Step6 機能詳細
## ワーク6-1
| 機能名 | 利用者 | 入力・操作 | 処理内容 | 正常時 | 異常時 |
| ---- | ---- | ---- | ---- | ---- | ---- |
| ログイン | 社員・管理者 | ログインボタン | 認証作業 | ログインできる | ログインエラーのメッセージを画面に出力 |
| ログアウト | 社員・管理者 | ログアウトボタン | - | ログアウトができる | ログアウトエラーのメッセージを画面に出力 |
| 出退勤登録機能 | 社員 | ボタン | 当該時刻で出退勤する | 成功通知を出す。 | フォーマットエラーや時刻エラーを画面に出力する |
| 記録表示機能 | 社員 | ボタン | DBから該当ユーザの記録を取得 | データを画面に出力 | エラー内容を画面に出力 |
| 画面表示機能 | 社員 | - | 現在時刻や該当ユーザの名前や部署名、ステータス（出勤/退勤）を表示する | - | エラーのメッセージを画面に出力 |
| 申請機能 | 社員 | 修正後の値入力後ボタン押下 | 修正値を一時領域に保存する。 | 画面にメッセージを出力 | エラー内容を画面に出力 |
| 承認機能 | 管理者 | 承諾ボタンを押下 | 一時領域に格納済みの対象データを本番DBに反映 | 画面にメッセージを出力 | エラー内容を画面に出力 |
| アカウント作成機能 | 管理者 | データ入力後作成ボタン押下 | DBに認証データを投入 | 画面にメッセージを出力 | エラー内容を画面に出力 |
| 残業申請機能 | 社員 | 最終時刻入力 | 労働時間超過分から入力時刻までの残業申請を一時領域に格納 | 申請完了通知 | 時刻エラー、エラーを画面に出力 |

| BR-007 | - |

# Step8 画面要件
## ワーク8-1
| 画面名 | 概要 |
| ---- | ---- |
| ログイン | IDとPassを入力し、ログインボタンがある |
| メイン画面（未ログイン） | 「ログイン」にリダイレクト |
| メイン画面（ログイン済み） | 画面中央に、現在時刻と出退勤と休憩終始ボタン、簡単残業代申請ボタンを設置、ヘッダー部分に氏名や部署名など表示、ハンバーガーメニューなどでその他機能へのアクセスボタン、ログアウトボタンも用意 |
| 簡単残業代申請（メイン画面ウィンドウ） | 退勤済みのみ使用可。終了時刻のみを入力して申請するだけ。時刻は退勤時刻以降の時刻を指定できない。 |
| 記録表示画面 | １画面１か月単位で出退勤のデータを確認、個別の日の箇所から修正および新規登録申請機能の画面へ遷移 |
| 申請画面 | 申請自体は小さいウィンドウが出てくる。カレンダから来た場合は対象日はすでに入っているが、そうでない場合は対象日から目的まで入れる必要あり。 |
| 承認画面 | 複数人から複数リクエストが来る想定。ＰＣではリスト型、スマホでは見やすさ重視でカード型で表示する。各項目毎に、承認ボタンと却下ボタンを用意。却下の際はコメントも可 |
