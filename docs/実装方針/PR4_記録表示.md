| 部分 | 内容 |

## 3. 出勤日数と総労働時間（D-049 の細部）

- **出勤日数**：表示中の月で、出勤の記録がある日の数。
- **1日の労働時間** ＝ 退勤 − 出勤 − 昼休憩 − 休憩。
  - 出勤と退勤の**両方がある日だけ**を数える（退勤が無い日は 0 として数えず、ウィンドウには「--」と表示）。
  - 昼休憩：勤務設定（`work_settings`）の 12:00〜13:00 のうち、出勤〜退勤と重なる分だけを引く。
  - 休憩：開始と終了の**両方がある場合だけ**引く（休憩終了が無い日は引かない。修正申請で直す）。
  - **休憩と昼休憩が重なる場合、重なった分は1回だけ引く**（二重に引かない）。
  - **残業（承認済みの残業終了時刻 `overtime_end_at`）は、労働時間の計算に使わない**（実際の退勤時刻で計算する）。
- **総労働時間**：表示中の月の、1日の労働時間の合計。表示は「160時間30分」。
- 時刻は分単位で記録しているため（D-059）、計算も分単位。

## 5. 依頼者が書くもの（仕様）

値は `bindValue` で渡す（D-060）。関数の `{` は関数名と同じ行（D-056）。枠には、処理の流れのコメントを書いておく（D-054）。

### 5-1. `fetchMonthlyAttendances()`（`src/queries/attendances.php` に追加）

| 項目 | 内容 |
| --- | --- |
| 関数 | `function fetchMonthlyAttendances(PDO $pdo, string $employeeId, string $fromDate, string $toDate): array {` |
| 引数 | `$fromDate`・`$toDate`：期間の初日と末日（例：`'2026-10-01'`、`'2026-10-31'`）。Claude の処理が作って渡す |
| 戻り値 | 行の配列（日付の順）。例：`[['work_date' => '2026-10-01', 'check_in_at' => '2026-10-01 09:01:00', 'check_out_at' => …, 'break_start_at' => …, 'break_end_at' => …], …]`。記録が無ければ空の配列 `[]` |
| SQL | `attendances` から `work_date, check_in_at, check_out_at, break_start_at, break_end_at` を取得。条件は `employee_id = :employee_id AND work_date BETWEEN :from_date AND :to_date`。並び順は `ORDER BY work_date` |
| ポイント | 初めての複数行の取得。`fetch()`（1行）ではなく **`fetchAll()`**（全部の行）を使う。行が無いときは `fetchAll()` が空の配列を返すので、そのまま返してよい（`null` にしない）。`BETWEEN` は、両端の日を含む |

### 5-3. 確認方法（依頼者の WSL）

1. メイン画面で「≡」を押し、メニューの「記録表示」を押す → 今月のカレンダーが出る。PR 3 で試した日に、出勤・退勤の時刻が出る。
2. 「＜」で前の月へ。入社した月（テストデータは 2025年4月）で「＜」が押せなくなる。今月で「＞」が押せない。
3. 祝日（例：2025年11月3日 文化の日、11月24日 振替休日）に名前が出る。
4. 日付を押す → その日の出勤・退勤・休憩・労働時間が出る。
5. 出勤日数・総労働時間が、3章の計算と合っている。過去の日の記録は、[DB構築手順書.md](../DB構築手順書.md) に追加する確認用の SQL で入れられる（枠と一緒に追加する）。

## 7. 確認したいこと（2026-10-15 すべて推奨どおりで承認。D-061）

1. **範囲と担当**（1章・4章）：依頼者が書くのは `fetchMonthlyAttendances()` の新規と、`fetchEmployeeProfile()` への入社日の追加でよいか。日付を押したときは、PR 4 では記録の表示だけにして、「修正」と申請は PR 5 でよいか。
2. **労働時間の細部**（3章）：D-049 で依頼者の確認待ちだった点。推奨は次のとおり。
   - 退勤が無い日は、総労働時間に含めない（D-049 のとおり。出勤日数には数える）。
   - 承認済みの残業は、労働時間の計算に使わない（実際の退勤時刻で計算する）。
   - 休憩終了が無い日は、休憩を引かない。
   - 休憩と昼休憩が重なる分は、1回だけ引く。
3. **月の範囲**（2章）：前の月は入社した月まで、次の月は今月まで。
4. **ハンバーガーメニュー**（2-1）：全画面のヘッダーに置き、記録表示の「＜ メイン画面」ボタンはメニューで代わりにする。
