# 実装 PR 8：CSS・JS のキャッシュ対策

状態: **承認済み（2026-10-22。D-068）**。作業ブランチ `claude/pr8-cache-busting` で実装・テストして、**PR #10 を作成、依頼者の承諾待ち**（5-3）。

## 1. 目的

- CSS・JS を変えたあと、Ctrl＋F5 を押さなくても、ブラウザが新しいファイルを読み込むようにする。
- これまでに3回、ブラウザのキャッシュ（前に読み込んだ古いファイル）が原因で、変更が画面に出なかった（T-022 の CSS、テスト用の JS、PR 7 の CSS）。

## 2. 原因

- ブラウザは、一度読み込んだ CSS・JS を覚えておき、**同じ URL** なら、しばらくは覚えている古いファイルを使う（表示を速くするため）。
- 今の URL は、ファイルの中身が変わっても `…/css/style.css` のまま変わらない。そのため、`git pull` で新しくしても、ブラウザは古いファイルを使い続けることがある。

## 3. 方法

CSS・JS の URL の後ろに、**ファイルを最後に変えた日時**（数字）を付ける。

```
変更前：/attendance/css/style.css
変更後：/attendance/css/style.css?v=1761100000
```

- `?v=…` は、サーバーには影響しない（Apache は `?` より後ろを無視して、同じファイルを返す）。ブラウザにとっては別の URL になるので、ファイルが変わると、自動で新しく読み込む。
- 日時は、PHP の `filemtime()`（ファイルを最後に変えた日時）で、画面を出すたびに自動で取る。**人が番号を書き換える必要はない**。
- `git pull` でファイルが変わると、そのファイルの日時が新しくなるので、URL も変わる。変わっていないファイルは、URL も変わらない（キャッシュが効いたまま、表示が速い）。
- 対象は、このアプリの CSS・JS（`css/style.css` と `js/` の6つ）。外部のもの（ress、Google Fonts）は、URL に版が入っていて変わらないので対象外。

### 3-1. 作る関数（`src/functions.php`）

```php
// CSS・JS の URL を作る。後ろに、ファイルを最後に変えた日時を付ける（例：/attendance/css/style.css?v=1761100000）
// ファイルを変えると URL が変わるので、ブラウザが古いファイル（キャッシュ）を使わなくなる
function assetUrl(string $path): string {
    $file = __DIR__ . '/../' . ltrim($path, '/');
    $time = is_file($file) ? filemtime($file) : false;
    return appUrl($path) . ($time === false ? '' : '?v=' . $time);
}
```

- ファイルが無いとき（打ち間違いなど）は、日時を付けずに今までどおりの URL を返す（画面はエラーにしない）。

### 3-2. 置き換える箇所

`appUrl('css/…')`・`appUrl('js/…')` を `assetUrl(…)` に置き換える（8か所）。

| ファイル | 対象 |
| --- | --- |
| `templates/header.php` | `css/style.css`、`js/menu.js`（全画面の共通） |
| `index.php` | `js/main.js` |
| `records/index.php` | `js/records.js` |
| `approvals/index.php` | `js/approvals.js` |
| `admin/accounts.php`・`admin/departments.php`・`admin/settings.php` | `js/admin.js` |
