# 解説（コードの教科書）

この勤怠管理システムのコードが「どういうものか」「何をしているのか」を、順番に読めるようにまとめた資料。

- 対象：2026-10-22 時点の `main`（PR 1〜8 をマージしたあと）。コードはこれからも変わるので、細かい行の位置ではなく、**ファイル名と関数名**で説明する。
- 読む人：このシステムの依頼者（DB まわりの関数を書いている人）。PHP・SQL・HTML の基本は知っている前提で、このシステムで使っている書き方と、その理由を中心に説明する。
- 用語：社員コード（`employee_id`）、申請（`attendance_requests`）など、DB の名前はそのまま使う。DB の表の一覧は [DB設計書.md](../DB設計書.md)。

## 全体を一言で

> **ブラウザ → Apache → PHP（画面ごとの PHP と `src/` の関数）→ MySQL** の順に処理が流れ、結果の HTML（または JSON）がブラウザに返る。
> 画面の PHP は「受け取る・確かめる・`src/` の関数を呼ぶ・HTML を出す」だけにして、計算やルールは `src/` に、SQL は `src/queries/` にまとめている。
